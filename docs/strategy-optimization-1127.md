# 工业模型策略优化（2026-11-27）

本次改动把训练策略从“每轮独立决定是否训练”升级为预算受限的
champion–challenger（冠军—挑战者）策略。目标不是让每轮都产生更新，而是
在不牺牲最终模型的前提下减少无效搜索。

## 策略

1. **冠军保留**：没有新训练数据、指标没有退化时，默认 `no_update`。
2. **周期探测**：B 在连续稳定轮次达到间隔且 CPU 预算充足时，允许一次
   `1 candidate x 1 epoch` 的低成本挑战；C 暂不自动探测。
3. **预算分级**：无退化但有新数据时使用受限的 idle search；只有明显漂移
   才进入任务默认的完整候选搜索。
4. **去重与早停**：同一父模型、同一数据变换的短候选如果已经被长候选覆盖，
   不再重复训练；逐 epoch 选择的候选在验证指标连续若干轮不改善时提前停止。
5. **安全审计**：C 的 NASA 非对称评分纳入本地辅助门控；C 的周期探测默认关闭。
6. **训练—门控对齐**：成员4在 C 的逐 epoch 选择阶段就计算 RMSE、MAE 和 NASA；
   如果某个候选的 NASA 相对父模型退化超过门控容差，会优先选择其他安全候选，
   避免把确定会被成员5拒绝的候选提交出去。
7. **输入标准化重拟合**：C 的候选只使用当前训练集重新拟合输入 `mean/scale`，
   再续训最多 8 个 epoch；验证集和隐藏集永不参与统计量拟合。

## C 漂移流对照

使用 `member2.compare`，C-MAPSS，3 个随机切分，10 轮：

| 指标 | 旧策略 | 新策略 | 变化 |
| --- | ---: | ---: | ---: |
| 隐藏集平均 RMSE | 63.8302 | 56.8374 | -10.96% |
| 训练 CPU 秒 | 33.96 | 18.34 | -46.0% |
| 隐藏集平均增益 | 10.22 | 15.35 | +50.2% |
| 隐藏集退化轮数 | 1.67 | 0.67 | -60% |

最差隐藏 RMSE 从 80.10 变为 80.71，基本持平；因此这是候选策略，
不是正式平台成绩，也不能替代完整 A/B/C 平台试运行。

## 回滚条件

如果后续对照出现以下任一情况，应恢复旧策略：

- 隐藏集平均指标持续变差；
- 最差阶段指标明显恶化；
- 周期探测造成连续拒绝或 CPU 预算提前耗尽；
- C 的 NASA 评分被门控拒绝比例异常升高。
