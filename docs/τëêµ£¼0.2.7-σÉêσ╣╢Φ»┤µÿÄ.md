## 保留的成员5 优点

- 有界探测 + 冷却：连续 4 个稳定轮后才探测一次，1 候选 × 1 epoch，CPU 剩余 ≥25%；连续 2 次探测失败冷却 8 轮；有退化或新数据时本轮训练优先。
- 决策提示 `member3-decision-v7`：稳定空闲轮只允许保持父模型或已验证回滚。

## 本版修正

1. **NASA 只报告、不否决**（`member5.evaluator.REPORT_ONLY_METRICS`，成员4 训练期门控同步）；C 的辅助否决只看 MAE。
2. **整次运行的第一次更新用完整搜索**（`member2.drift._update_hint`）：还没有任何上线时，按任务默认规模训练。
3. **C 候选顺序**：全量 + input-refit（最多 8 epoch）第一，近期窗口 + input-refit 第二，剪枝第三。
4. **B 候选顺序**：恢复 0.2.4 的核心（按轴承分组的最近 30% 窗口最多 3 epoch、全量 1 epoch）；全局尾部、剪枝、低学习率等作为可选挑战者，历史上胜出时可被提升。
5. **早停**保留（fix-1127 的 `early_stop_patience`）；前缀去重的“训练身份”包括全部配方字段。
6. **行摘要**改为不经 JSON 的字节哈希（只有读到旧 Bloom 状态时才算 JSON 摘要）；`rows.npz` 可被状态预算裁剪。
7. **swanlab 不进镜像**（可选依赖 `.[swanlab]`），镜像测试要求镜像内没有 swanlab：正式评测离线且禁止未授权外网访问。平台运行用 `scripts/upload_platform_runs.py` 事后补记。
