# 平台试运行清单（试运行 → 正式评测）

正式评测机会只剩 3 次（校赛加 1 次后共 3 次，已用 0 次有效），每次都要先在试运行里把下面的项目看一遍。

## 0. 构建镜像（在 WSL2 / Linux）

```bash
git pull
bash scripts/build_image.sh zhixun-harness:0.1.0          # 正式镜像：configs/harness.full.json
HARNESS_CONFIG=/app/configs/harness.trial.json \
  bash scripts/build_image.sh zhixun-harness:trial         # 试运行镜像：第 3 轮强制回滚一次
bash scripts/verify_image.sh zhixun-harness:0.1.0          # 5 步验收，最后一步跑 tests/test_image.py
docker save -o zhixun-harness-0.1.0.tar zhixun-harness:0.1.0   # 上传单个未压缩 tar，不要 gzip
```

`build_image.sh` 会把 `git rev-parse HEAD` 写进镜像（`ZHIXUN_GIT_COMMIT`），有未提交改动时标 `-dirty`。
`verify_image.sh` 第 5 步需要本机装好 SDK 和 pytest（`pip install ./contest-harness-sdk-1.0.4.tar.gz -e ".[dev]"`）。

## 1. 试运行镜像要看什么

试运行镜像（`harness.trial.json`）与正式镜像只差一个 `trial` 字段：

| 字段 | 作用 |
| --- | --- |
| `force_rollback_round: 3` | 第 3 轮若存在“曾经上线、平台可恢复”的历史模型，就强制回滚到最近的一个 |
| `bypass_rollback_gate: true` | 回滚目标即使在当前验证集上没有更好也选它（只为验证平台的恢复路径） |

在平台的每轮记录里检查：

1. **每轮都有 `round_complete`**：没有 `round_failed`。流程出错时我们会保留父模型并照常 finish，
   这时 `configuration.fallback = true`、`final_action = failed`，`configuration.failed_stage` 写着出错步骤。
2. **`configuration.evidence`**：每轮都有，里面是本轮动作、父模型成绩、候选成绩、门控结果、预算用量。
3. **`hypothesis`** 是可读的中文（诊断 → 归因 → 假设 → 证据 JSON），不超过 4000 字节。
4. **第 3 轮**：
   - `configuration.evidence.trial.force_rollback` 是一个 artifact id → 看 `selected_artifact_id`
     是否就是它，平台是否接受（ack accepted），下一轮父模型是否变成它。
   - 如果是 `no_restorable_target`，旁边的 `frame_artifacts` 列出平台这一轮给的 artifact 列表：
     说明平台没有把历史 artifact 放进帧里（或前两轮没有上线新模型），把这个结果告诉成员 1。
5. **Qwen 回复**：`members/decision/latest.json`（状态目录）里 `status` 应主要是 `model`，
   偶尔 `model_retry`（第一次回复不合格、重问一次后合格）；大量 `fallback` 说明模型输出格式有问题。
6. **耗时**：每轮训练时间、预测阶段时间（预测现在每个进程只加载一次模型）。

## 2. 正式评测

试运行全部正常后再用正式镜像（`zhixun-harness:0.1.0`，没有 `trial` 字段）。正式镜像里回滚只在
“曾上线的模型在当前验证集上确实更好”时才会生效（成员 2 给出 `rollback_hint`，成员 1 在选择前用门控复核）。

## 3. 出问题时先看哪里

| 现象 | 位置 |
| --- | --- |
| 某轮 `final_action = failed` | 该轮 `configuration.failed_stage` / `evidence.error`；本地 `records/failed-round-*.json` |
| 回滚没生效 | `evidence.rollback`：`gate`、`delta`、`restored_metrics`、`selected` |
| 候选没上线 | `evidence.gate`：`keep` = 没有足够提升；`reject`（门控 `rollback`）= 候选更差或辅助指标退化 |
| 状态丢失 | 状态目录 `datasets/<slot>/round-log.json`、`lineage.json`；状态文件数上限 64 |
